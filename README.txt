# Financial Data Analysis Project (FinRobot)

## Overview
This project builds an automated financial analysis pipeline using Python to process company reports and generate structured insights.

## Key Features
- Processed annual reports of major companies (AAPL, GOOGL, NVDA, AMD, INTC)
- Built data preprocessing and analysis pipeline
- Generated structured financial insights using Python
- Implemented automated report generation with FinRobot framework

## Tools & Technologies
- Python
- Pandas
- Jupyter Notebook

## Files
- `agent_annual_report_clean.ipynb`: main analysis notebook
- Financial reports (PDF): raw data inputs
